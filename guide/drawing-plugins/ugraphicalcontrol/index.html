uGraphicalControl

Where to find it

Applications & Components → Comma → uGraphicalControl

Assigns rebar orientation/scale UDAs (used for graphical bar control) to bars matching a Mark search text.

Option What it does
Bar rotation By local axis, By view, or By global Z — how the bar’s graphical control reads its rotation.
Bar scale type Yes/No — whether the bar’s graphical control scales with the view.
Mark search A wildcard search on Mark, to target only the bars you mean (leave blank to affect all visible bars).
